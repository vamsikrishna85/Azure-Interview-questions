# Azure Infrastructure Interview Questions & Answers

A growing collection of **Azure Infrastructure interview questions, answers, and scenario-based discussions**, organized company-wise to help cloud professionals prepare for technical interviews.

## 📌 About This Repository

This repository collects Azure Infrastructure interview experiences and technical questions from different companies. Each company has its own folder, making it easy to browse questions and add new companies over time.

## 📚 Topics Covered

Questions may cover:

- Azure Virtual Machines and compute
- Azure networking (VNets, NSGs, VPN Gateway, ExpressRoute)
- Azure Load Balancer and Application Gateway
- Azure Storage, Backup, and recovery
- Microsoft Entra ID and role-based access control (RBAC)
- Azure security and governance
- Azure Monitor and Log Analytics
- Azure Site Recovery and disaster recovery
- High availability and Azure architecture
- Real-world troubleshooting and scenario-based questions

## 🚀 How to Use

1. Find a company in the **Company-Wise Interview Questions** table.
2. Open its folder to explore the available questions.
3. Practice explaining concepts, trade-offs, and troubleshooting steps.
4. Check back as new company folders and questions are added.

**Interview tip:** Focus on understanding the reasoning behind solutions rather than memorizing answers.

## 🤝 Contributing

Contributions are welcome! You can add questions from new companies, improve answers, share troubleshooting scenarios, or correct outdated information.
